# Sarasa UI SC / 更纱黑体

Bundled locally for offline use. The regular and semibold faces are from
[Sarasa Gothic v1.0.43](https://github.com/be5invis/Sarasa-Gothic/releases/tag/v1.0.43),
asset `SarasaUiSC-TTF-Unhinted-1.0.43.7z`.

The original TTF faces were converted to WOFF2 with fontTools. All glyphs and
original font names are retained; the files are not character subsets.
Copyright and SIL Open Font License 1.1 are in [OFL-Sarasa.txt](OFL-Sarasa.txt).
