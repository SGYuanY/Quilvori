# Realmweave · 织境

キャラクターを書き、世界を組み立て、散らばった設定を使いやすく整えるローカルの作業机です。✍️

[中文](README.md) · [English](README.en.md) · **日本語** · [Русский](README.ru.md) · [한국어](README.ko.md) · [ไทย](README.th.md)

Realmweave は SillyTavern 用の素材を作るためのアプリです。キャラクターカードやワールドブックを編集し、自分で設定したモデルと相談して推敲し、SillyTavern に読み込めるファイルへ書き出せます。手動編集、インポート、ローカル検査、バックアップは単独で使えます。AI 機能には別途モデルサービスが必要です。

## できること

- 外見・背景、性格、シナリオ、挨拶、会話例、ロールプレイ指示を編集し、プレビューで確認。
- 一つの欄に混在した設定を、原文と移動先の既存内容を保ったまま適切な欄へ整理。
- 無題のワールドブック項目に名前、分類、主キーワードを補い、本文は保持。
- 選択した欄、項目、文章だけを AI に修正してもらい、比較してから反映・取り消し。
- 採用したアイデアと現在の下書きを使って相談し、続きを修正。
- 人物設定、事実、時系列を検査し、引用と読みやすい原文の場所を確認。
- プロンプト、正規表現、クイック返信、関係図、時系列、HTML 記憶を管理。

## クイックスタート

リポジトリをダウンロードするか、Git で取得します。

```bash
git clone https://github.com/ShangguanQian/sillytavernworks.git
cd sillytavernworks
```

### ウェブ版

Python 3 と新しいブラウザーが必要です。ウェブ版に npm 依存関係のインストールやビルドは不要です。

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

Windows では次も使えます。

```powershell
py -m http.server 8765 --bind 127.0.0.1
```

[http://127.0.0.1:8765/](http://127.0.0.1:8765/) を開き、使用中はサーバーを動かしておきます。別のポートも使えますが、ポートが異なるとブラウザーのライブラリも別になります。

`index.html` を直接開く方法もあります。ファイルページでの保存や API 通信が制限される場合はローカル HTTP サーバーを使ってください。保存できない状態で閉じる前には、ライブラリ全体をバックアップします。

### デスクトップ版

Node.js LTS と npm を用意し、リポジトリ直下で実行します。

```bash
npm install
npm start
```

Electron が同じ画面を開きます。Python サーバーは不要です。デスクトップ版では選択したローカルフォルダーからカードやワールドブックを読めます。現在はソースから起動する方式で、Windows 用インストーラーは同梱していません。

## 初めて使うとき

1. 新しいライブラリには「听雨楼」のサンプルが入ります。編集、検査、書き出しを試せます。「未名客」は空欄を残した下書きです。
2. サイドバーからカードの JSON／PNG、ワールドブックの JSON を取り込みます。対応ページへのドラッグ＆ドロップも使えます。
3. カードの「項目を整理」やワールドブックの AI 整理で、既存の資料を整えます。
4. 書き換える場合は「AI 創作」の既存編集で範囲を選び、要求を入力します。
5. プレビューを確認して必要な提案を反映し、SillyTavern 用に書き出します。全体バックアップも保存してください。

サンプルの読み込みとライブラリ消去には確認があります。サンプルを再読み込みすると現在のライブラリを置き換えるため、自分の資料は先にバックアップしてください。

## AI モデルの接続

設定のモデル接続画面で次を行います。

1. `https://api.openai.com/v1` など、利用先の API ベース URL を指定します。個々のリクエストの完全な URL は入れません。
2. 自分の API キーとプロトコルを設定し、接続します。
3. サービスが返した一覧からモデルを選び、短いテストメッセージで接続を確認します。
4. 必要に応じて推論強度を選びます。既定値では追加パラメーターを送信しません。対応段階はモデルとサービス次第です。

OpenAI 互換の **Responses** と **Chat Completions** に対応しています。自動では Responses を優先し、エンドポイントが未対応の場合に切り替えます。Chat Completions のみのサービスでは、その方式を直接選べます。認証失敗や不正な応答はエラーとして表示します。

推論強度が高いほど通常は時間がかかります。未対応の強度なら既定値か対応段階へ戻してください。利用可否、生成品質、料金は利用するモデルサービスによります。

手動作業はオフラインでも行えます。AI の生成・整理・相談・検査を実行すると、選んだ原文、参考資料、要求、関連する会話を設定先の API に送ります。キーはブラウザーまたはデスクトップ版のローカル保存領域に置かれ、カードやライブラリバックアップには含めません。

## AI の使い分け

### 既存の資料を修正

カードかワールドブックを選び、編集してよい欄や項目を指定します。原文内の選択範囲だけを修正することもできます。他の資料は参考として使い、修正前後を比較してから反映します。

返されなかった欄は元の値を保持します。既存内容の消去には明示的な許可が必要です。確認質問、不完全な応答、範囲外の変更、待機中の原稿変更は自動で上書きしません。取り消しも、その後の手動編集を上書きしないよう検査します。

### 新規作成と下書きの継続

目的を書き、作るモジュールを選びます。必要な質問に先に答えたり、複数のアイデアを出してもらったりできます。後の生成条件に入るのは採用したアイデアだけです。

相談には現在の下書きと採用済みのアイデアを含めます。構成を相談するだけでも、追加要求で下書きを更新することもできます。生成途中に要求を送ると現在の出力を止め、完成済みの下書きは保持します。カードとワールドブックのプレビューでは一部分だけの再編集もできます。

生成物はまずプレビューに入り、確認後にライブラリへ追加します。新しい人物を参照するグループチャット・台本・関係図は、その人物カードを先に反映してください。

### 論理と人物設定の検査

ローカルルールと AI 検査は分けて表示します。報告には平易な結論、理由、対応案があり、引用の場所をカードの欄、または「ワールドブック → 項目 → 欄 → 行」で示します。

原文を開いて確認し、報告へ戻れます。報告は生成時の引用位置を保持し、原稿が変わると再検査を促します。任意の空欄は注意に留め、根拠が不足する差異は確認事項として扱います。検査そのものは原稿を書き換えません。

大きなワールドブックは項目を選んで分割検査でき、対象範囲を明記します。タスク記録では進行状態、サービスが返した推論、結果を区別し、推論が返らなかった場合も明示します。

## カードの項目整理

カード編集画面で整理を開き、任意の分類方針を添えてプレビューを作ります。

- 説明、性格、シナリオ、最初の挨拶、会話例、システム指示、履歴後指示、作者メモを対象にします。
- 各提案で移動元、移動先、理由、欄ごとの前後を確認できます。
- 原文をそのまま移し、移動先に既にある文章へ追記します。未選択の部分や判断できない部分は元の場所に残します。
- 移動元からの除去と移動先への追加は同時に反映します。引用不一致、重複範囲、原稿の変更があると反映しません。

既存資料の整理なので、足りない経歴を創作しません。分類結果は確認し、任意欄は必要がなければ空白のままで使えます。

## ワールドブックの整理

現在の項目、無題またはトリガー語が不足する項目、現在の本の全項目を選べます。項目編集側から一項目だけを開くこともできます。

- 人物、関係、場所、組織、ルール、歴史、品物、物語、その他に分類し、一覧を内容別に切り替えられます。
- 既定では無題・新規項目の名前だけを補います。既存名の変更は別途許可します。
- 主キーワードは本文または元の項目名から選び、既存の主・副キーワードを保って追加します。
- 常時有効の項目にキーワードは必須ではありません。常時有効の方式変更は、専用の許可を選んだ場合のみ提案します。
- キーワード方式へ変えるには主キーワードが最低一つ必要です。本文、有効状態、選択条件、挿入位置、深さ、順序は整理でリセットしません。

根拠と理由を確認し、選択した項目を反映・取り消しできます。分類は書き出し時に `realmweave_category` 拡張へ保存され、SillyTavern の発火設定とは別の情報です。

## 画面とツール

| 画面 | 用途 |
| --- | --- |
| 作業机 | 最近の原稿、カード、本、よく使う操作。 |
| キャラクターカード | カードの欄を編集し、JSON・カード PNG を入出力。 |
| ワールドブック | 項目と挿入設定、発火テスト、位置別・内容別の一覧。 |
| AI 創作 | 範囲指定編集、新規作成、相談、検査、反映プレビュー。 |
| 文章プリセット | 文体、視点、関係、境界、出力形式を組み合わせる。 |
| プロンプト構成 | ブロックの並べ替えと有効化。 |
| グループチャットキャスト | メンバー、シナリオ、話す頻度や方式を設定。 |
| チャット閲覧 | JSONL／メッセージ配列の検索、ブックマーク、コピー。 |
| 素材 | アバター、表情、背景をライブラリに保存。 |
| 正規表現 | SillyTavern Regex 拡張形式を編集・書き出し。 |
| クイック返信 | ボタンと文面を編集し Quick Reply v2 へ書き出し。 |
| 作者注と時系列 | 会話位置に応じた注記や出来事。 |
| 関係図 | 人物と関係線を編集し、ワールドブックへ書き出し。 |
| 整合性検査 | ローカル・AI 報告と原文への移動。 |
| グループチャット台本 | 台詞、地の文、トリガーを順に配置。 |
| HTML 記憶 | JS-Slash-Runner 用 HTML 記憶を作成。 |
| 全体バックアップ | ライブラリを保存し、置換または結合で復元。 |
| ガイド | 操作と書き出し先の説明。 |

外観、言語、創作設定、モデルは設定画面で変更します。中国語 UI には同梱の Sarasa フォントを使います。UI は六言語に対応し、切り替えても書いた本文は翻訳・改変しません。

## SillyTavern への入出力

| 資料 | 形式と読み込み先 |
| --- | --- |
| カード | `chara`／`ccv3` データ入り PNG または JSON。酒館の人物インポートを利用し、書き出し時には本も添付可能。 |
| ワールドブック | World Info JSON／キャラクターブックの `entries` 配列。世界情報から読み込み。 |
| 正規表現 | JSON 配列を Regex 拡張から読み込み。 |
| クイック返信 | Quick Reply v2 JSON を対応拡張から読み込み。 |
| 表情 | 対象人物の `expressions` フォルダー。本が記録するのはパック名だけです。 |
| プロンプト | 酒館プリセットと比較するブロック設定。モデル・温度を含む API プリセット全体の代わりではありません。 |
| グループチャット | 人物を読み込んでから群を作るための名簿。共通の群インポート形式ではありません。 |
| チャット・時系列・台本 | 工房独自の閲覧・構成ファイルで、酒館の chats へ直接書き戻しません。 |
| HTML 記憶 | 酒館助手／JS-Slash-Runner で HTML スクリプトとして読み込み。 |
| 全体バックアップ | Realmweave 用 JSON。SillyTavern サーバー全体のバックアップではありません。 |

### ローカルフォルダーを読む

デスクトップ版でローカルフォルダー欄を開き、人物・世界書のフォルダーを選んで既存ファイルを読み込みます。対象は選んだフォルダー直下のカード JSON／PNG と世界書 JSON です。カード内の本も取り込みます。

重複は省略し、元ファイルが更新された場合は別版として追加してローカル編集を残します。一つのファイルが失敗しても残りを続行し、詳細に失敗理由を表示します。大きなアバターは縮小し、容量不足では新規画像を省略して文章を保存できる場合があります。読み込みは元カード・世界書を変更しません。表情の明示的な書き出しは選択先へ書き込みます。

## 保存・バックアップ・更新

資料はブラウザーまたはデスクトップ版の `localStorage` に保存し、GitHub へ自動コミットしません。ブラウザープロファイル、ポート、`localhost` と `127.0.0.1`、ファイルページと Electron は別ライブラリになり得ます。いつも同じ入口を使い、移行には全体バックアップを利用します。

Windows デスクトップ版は互換性のため `%APPDATA%\nijan` にユーザーデータと `folders.json` を保存します。表示上の名前は Realmweave／织境です。

バックアップにはカード、本、画像などの作品が含まれます。自分で管理できる場所へ保存し、端末・ブラウザー・ポートの変更や更新前に書き出してください。Git の無視設定だけに頼らず、コミット前にステージ済みファイルを確認してください。

未処理のコード変更がなければ、次で更新できます。

```bash
git pull --ff-only
npm install
```

その後アプリを再起動するかページを更新します。ウェブ版のみなら `npm install` は不要です。ローカルコードの変更は更新前に保存・整理します。

## よくある問題

**人物一覧が空です。** 元と同じブラウザー、ポート、デスクトップ入口か確認します。ウェブ版ではファイルを取り込み、デスクトップ版では設定済みフォルダーを読めます。選んだフォルダーが別ブラウザーの庫へ共有されるわけではありません。

**PNG が取り込めません。** 普通の画像にはカードデータがありません。有効なカード PNG、または酒館から出した JSON を使います。

**接続・生成が失敗します。** URL、キー、モデル、方式を確認します。Chat Completions のみなら明示的に選びます。ブラウザーのクロスオリジン通信はサービス側の設定に依存します。切断や容量超過では対象を減らして分割します。

**推論強度が拒否されます。** モデルの既定値または対応する段階へ戻します。

**保存容量が足りません。** 先にバックアップし、大きな画像を減らします。復元できることを確認せずブラウザーデータを消さないでください。

**酒館へ自動で反映されません。** 工房の庫と酒館のファイルは別です。書き出して対応する画面から取り込みます。

## 検証とソース

```bash
npm test
```

テストはサンプルと模擬 API を使い、有料モデルを呼びません。入出力、重複防止、原文移動、メタデータ整理、編集範囲、空欄、古いプレビュー、反映・取り消し、引用根拠、通信方式、推論設定、多言語を検証します。

`js/` は UI・ライブラリ・AI 処理、`electron/` はファイル連携、`css/` は外観、`test/` は自動検証です。ウェブ版は通常のスクリプトを使い、バンドラーは不要です。
