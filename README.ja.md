# 织境

[中文](README.md) · [English](README.en.md) · 日本語

![织境](img/mark.svg)

ひとつの想いから、人物と世界を書く。

英語名は Realmweave。SillyTavern 用の素材をローカルで書く工房です。SillyTavern の代わりにはなりません。原稿はブラウザに残ります。書き出したファイルは SillyTavern が読み込め、SillyTavern から書き出したファイルも読めます。モデルの鍵はこのブラウザのローカルストレージだけに残します。リポジトリにも、書き出した原稿にも入りません。

## 開く

ウェブ:

```bash
python3 -m http.server 8765
```

<http://127.0.0.1:8765/> を開きます。デスクトップ:

```bash
npm install
npm start
```

`npm start` は同じページを Electron で開きます。ページには人物カードのフォルダとワールドブックのフォルダが出ます。デスクトップ版ではその二つのフォルダを選び、中にある JSON を読めます。このリポジトリに Windows 用インストーラはありません。

`index.html` を直接開くこともできます。スクリプトは ES Module ではありません。ファイルページで保存が禁じられているときは、離れる前にライブラリ全体を書き出してください。

ウェブ版にビルドは要りません。

## SillyTavern ではどこに置くか

- 人物カードの JSON または PNG: SillyTavern の `characters`。または人物リストから読み込む。表情画像はその人物の `expressions` に置く。
- ワールドブック JSON: SillyTavern の `worlds`。またはワールド情報から読み込む。ワールドブックに残るのは表情パックの名前だけで、画像は入らない。
- 正規表現 JSON: 正規表現拡張で読み込む。
- クイック返信 JSON: Quick Reply 拡張で読み込む。
- チャット閲覧の書き出しは工房自身の読書用ファイルです。SillyTavern の `chats` には書き戻しません。
